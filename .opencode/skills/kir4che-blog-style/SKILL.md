# kir4che 寫作風格指南

## 語言基調

- **口語化、像聊天**：句子短、自然，像跟朋友坐在咖啡廳講話，不是演講或論文
- **誠實吐槽**：難吃直接說、貴直接說、失望直接說，不用場面話
- **大量表情符號/顏文字**：`XDDD` `(´⌣`ʃƪ)` `｡:.ﾟヽ(\*´∀`)ﾉﾟ.:｡` `(((o(°▽°)o)))` `(っ˘ڡ˘ς)` `(◞‸◟)` `(๑•͈ᴗ•͈)` `༶ඬ༝ඬ༶` `ヾ(●´▽｀●)ノ`
- **注音文/網路用語**：`ㄏㄏ`、`RRRRR`、`幹`（限日記型文章）
- **自嘲**：「文筆不好」、「不會畫畫」、「超級緊張」、「很丟臉」
- **重複強調詞**：「超級」、「超」、「真的」、「好」、「最」

## 文章開頭公式

### 技術文章

```
最近[遇到什麼問題]，查了一大堆文章/找了好久，[耗費時間]，終於解決了，這邊記錄一下。
```

範例：

- 「最近在重構一個專案，更新後發現 Vercel 部署那邊壞掉……找了好久，嘗試很多方法，最後終於解決了，這邊記錄一下。」
- 「最近在工作上遇到需要 Squash Commits 的情況……瘋狂查了一堆文章……卻總是缺了一點小細節……我打算簡單整理一篇文章，記錄自己的操作步驟。」

### 旅遊文章

直切行程，偶爾加搭乘心得或出發契機。大量圖片、餐廳評分、花費統計。

### 日記/個人故事

直接從一句情緒或回憶開始：「我最後悔的是沒有多問我媽媽的人生」

## 文章結構慣例

### 技術筆記型

1. 動機說明（為什麼寫這篇）
2. 核心概念說明（常搭配比喻）
3. 表格比較（`<Table>` 元件）
4. 實作步驟（附程式碼）
5. 補充說明（`<Accordion>`、`<Alert>` 元件）
6. 參考資料

### 旅遊遊記型

1. `## 🗓 行程安排`
2. 每日行程 `### Day N [地名]`
3. 景點 `#### [名稱]`
4. 餐廳評價區塊：
   ```
   > **[店名]**
   >
   > <Rating rating={X} />
   > [一句心得]
   >
   > **地址**：[地址]
   >
   > **營業時間**：[時間]
   ```
5. 內部錨點 `||anchor-name||`
6. 結尾花費統計 `## 💸 個人花費`
7. 參考行程連結（Funliday）

### 開發日記型

1. 起心動念（為什麼想做這個）
2. 現有工具/作品啟發
3. 技術選型過程
4. 目前進度條列
5. 目前困境 & 下一步

## MDX 元件完整參考

所有元件從 `@/components/mdx/` 匯出，可在 `.mdx` 中直接使用：

### `<Image>`

單張圖片，支援燈箱。`src` 為必要。

| Prop         | 型別                        | 預設值     | 說明                                 |
| ------------ | --------------------------- | ---------- | ------------------------------------ |
| `src`        | `string`                    | —          | 圖片 URL（僅允許 `cdn.kir4che.com`） |
| `alt`        | `string`                    | `''`       | 替代文字                             |
| `title`      | `string`                    | —          | 圖說（顯示於圖片下方）               |
| `width`      | `string\|number`            | —          | 寬度，如 `'240px'` 或 `560`（px）    |
| `height`     | `string\|number`            | —          | 高度                                 |
| `align`      | `'left'\|'center'\|'right'` | `'center'` | 水平對齊                             |
| `objPos`     | `'top'\|'center'\|'bottom'` | `'center'` | 圖片裁切焦點                         |
| `noLightbox` | `boolean`                   | `false`    | 設 `true` 關閉點擊燈箱               |

### `<Images>`

圖片/影片 Grid。`images` 陣列中的每項為 `MediaItem` 型別。

| Prop        | 型別                        | 預設值     | 說明          |
| ----------- | --------------------------- | ---------- | ------------- |
| `images`    | `MediaItem[]`               | `[]`       | 圖片/影片陣列 |
| `title`     | `string`                    | —          | 整組圖說      |
| `width`     | `string\|number`            | `'85%'`    | 容器寬度      |
| `minWidth`  | `string\|number`            | `'150px'`  | 每項最小寬度  |
| `height`    | `string\|number`            | —          | 固定高度      |
| `minHeight` | `string\|number`            | —          | 最小高度      |
| `maxHeight` | `string\|number`            | —          | 最大高度      |
| `align`     | `'left'\|'center'\|'right'` | `'center'` | 對齊方式      |

`MediaItem` 可為圖片或影片：

```ts
// 圖片
{ src: string; alt?: string; colSpan?: number; width?: string|number; height?: string|number; objPos?: 'top'|'center'|'bottom' }

// 影片
{ type: 'video'; src: string; colSpan?: number; autoPlay?: boolean; loop?: boolean; muted?: boolean; controls?: boolean }
```

技巧：`colSpan` 控制該項佔比（值越大越寬），圖片會自動開燈箱，影片不會。

### `<Table>`

比較表格，技術文章必備。

| Prop           | 型別         | 說明                                            |
| -------------- | ------------ | ----------------------------------------------- |
| `data.headers` | `string[]`   | 表頭列                                          |
| `data.rows`    | `string[][]` | 每列資料，支援 `**粗體**` 和 `` `行內程式碼` `` |

支援自動合併相同內容的相鄰儲存格。

### `<Rating>`

餐廳/商品評分元件。

| Prop     | 型別               | 預設值   | 說明                  |
| -------- | ------------------ | -------- | --------------------- |
| `type`   | `'star'\|'heart'`  | `'star'` | 星星或愛心            |
| `rating` | `number`           | —        | 0-5 分，支援 0.5 間隔 |
| `size`   | `'sm'\|'md'\|'lg'` | `'sm'`   | 大小                  |

### `<Accordion>`

摺疊面板，放補充故事或詳細說明。

| Prop       | 型別                         | 預設值      | 說明                                    |
| ---------- | ---------------------------- | ----------- | --------------------------------------- |
| `variant`  | `'default'\|'basic'\|'pink'` | `'default'` | `'pink'` 為圓角標籤式，`'basic'` 無邊框 |
| `title`    | `string`                     | —           | 折疊標題                                |
| `children` | `ReactNode`                  | —           | 內容                                    |

### `<Alert>`

提示框。

| Prop       | 型別                                | 預設值   | 說明                         |
| ---------- | ----------------------------------- | -------- | ---------------------------- |
| `type`     | `'tip'\|'note'\|'warning'\|'error'` | `'note'` | 類型（顏色不同）             |
| `title`    | `string`                            | —        | 自訂標題（預設用 type 名稱） |
| `children` | `ReactNode`                         | —        | 內容                         |

### `<Highlight>`

螢光筆強調。

| Prop       | 型別                                | 預設值   | 說明     |
| ---------- | ----------------------------------- | -------- | -------- |
| `color`    | `'pink'\|'yellow'\|'green'\|'blue'` | `'pink'` | 高亮顏色 |
| `children` | `ReactNode`                         | —        | 文字     |

### `<Card>`

概念對照卡，常用於 `grid-cols-1 md:grid-cols-2` 搭配。

| Prop          | 型別        | 說明                                        |
| ------------- | ----------- | ------------------------------------------- |
| `title`       | `string`    | 標題                                        |
| `subtitle`    | `string`    | 副標題（較大字體）                          |
| `description` | `string`    | 說明文字                                    |
| `children`    | `ReactNode` | 自訂內容（取代 title/subtitle/description） |

### `<Badge>`

徽章標籤。

| Prop    | 型別                                                           | 預設值   | 說明     |
| ------- | -------------------------------------------------------------- | -------- | -------- |
| `text`  | `string`                                                       | —        | 顯示文字 |
| `color` | `'blue'\|'red'\|'yellow'\|'orange'\|'green'\|'purple'\|'pink'` | `'blue'` | 顏色     |

### `<Video>`

影片播放器。

| Prop               | 型別                        | 預設值                          | 說明                   |
| ------------------ | --------------------------- | ------------------------------- | ---------------------- |
| `src`              | `string`                    | —                               | 影片 URL               |
| `title`            | `string`                    | —                               | 圖說                   |
| `width` / `height` | `string\|number`            | `100%` / `auto`                 | 尺寸                   |
| `autoPlay`         | `boolean`                   | `false`                         | 自動播放（需 `muted`） |
| `loop`             | `boolean`                   | `false`                         | 循環播放               |
| `muted`            | `boolean`                   | `true`                          | 靜音                   |
| `controls`         | `boolean`                   | `true`(非 loop) / `false`(loop) | 顯示控制列             |
| `poster`           | `string`                    | —                               | 預覽封面               |
| `align`            | `'left'\|'center'\|'right'` | `'center'`                      | 對齊                   |

### `<Kbd>`

鍵盤按鍵樣式。

```mdx
<Kbd>Enter</Kbd>
<Kbd>Ctrl + C</Kbd>
```

### `<Correction>`

正誤對照。滑鼠懸停顯示錯誤原文。

```mdx
<Correction wrong="錯誤寫法" correct="正確寫法" />
```

### `<SmallText>`

小字備註。

```mdx
<SmallText>這是備註說明</SmallText>
```

### `<Spoiler>`

劇透隱藏（限生活類文章）。預設模糊，滑鼠懸停或選取時揭示。

```mdx
<Spoiler>被隱藏的內容</Spoiler>
```

### `<FigureShell>`

通用圖形容器。給自訂內容加上圖說。

| Prop    | 型別                        | 預設值     | 說明     |
| ------- | --------------------------- | ---------- | -------- |
| `align` | `'left'\|'center'\|'right'` | `'center'` | 對齊     |
| `title` | `string`                    | —          | 圖說文字 |

### `<Link>`

內部/外部連結。內部自動處理語系路由。

| Prop       | 型別         | 說明     |
| ---------- | ------------ | -------- |
| `href`     | `string`     | 路徑     |
| `lang`     | `'tw'\|'en'` | 語系     |
| `children` | `ReactNode`  | 連結文字 |

### `H1` ~ `H6`

自訂標題層級（透過 `Headings` 匯出）。

```mdx
<H2 id="my-section">段落標題</H2>
```

### Lightbox（非元件，透過 `Image` / `Images` 自動觸發）

點擊圖片自動開燈箱全螢幕檢視。也可手動呼叫：

```tsx
import { openLightbox } from '@/components/mdx/Lightbox';

openLightbox({
  slides: [{ src: '...', alt: '...' }],
  index: 0,
});
```

### 常用搭配範例

**餐廳評價區塊（旅遊文必用）：**

```mdx
> **[店名]**
>
> <Rating rating={4} />
> 一句心得
>
> **地址**：[地址]
> **營業時間**：[時間]
```

**技術比較表格：**

```mdx
<Table
  data={{
    headers: ['特性', '方案A', '方案B'],
    rows: [
      ['效能', '快', '慢'],
      ['設定', '**簡單**', '`複雜`'],
    ],
  }}
/>
```

**補充故事：**

```mdx
<Accordion variant="pink" title="笑不停的詳細故事">
  這裡放長一點的故事內容
</Accordion>
```

**注意提示：**

```mdx
<Alert type="warning">這裡放需要注意的重要資訊</Alert>
```

**強調重點：**

```mdx
<Highlight color="yellow">預設不送任何 JavaScript 到瀏覽器</Highlight>
```

## 程式碼區塊風格

- 使用 expressive-code 語法，加 `title=` 標示檔名
- 使用 `ins={}` `del={}` 標記新增/刪除行
- 使用 `{3-5}` 標記高亮行
- Shell command 簡潔，不加過多註解

## 常用詞彙與句式

### 評價用語

- 好吃程度：「超好吃」、「世紀好吃」、「普普通通」、「一般般」
- CP 值：「很划算」、「有點偏貴」、「盤子」
- 失望表達：「有點後悔」、「毀掉整碗」、「吃到後面很痛苦」

### 過渡用語

- 「幸好」、「結果」、「然後」、「後來」、「因為...所以...」
- 「不得不說」、「真的很」、「完全」

### 問句/呼告

- 「（？」—— 打個問號錶疑惑
- 「RRRRR」—— 崩潰
- 破折號、刪節號連用

## 要注意避免

- ❌ 太正式、像教科書
- ❌ 太多被動語態
- ❌ 沒有個人觀點的中立敘述
- ❌ 不熟的技術名詞裝懂
- ❌ 旅遊文沒放圖片

## 技術類標籤慣例

- 筆記型文章加 `notes` 標籤
- 類別用大寫開頭：`Frontend`、`DevOps`、`CSS`、`NodeJS`
- 旅遊類別用 `Trip`，地區標籤 `Japan` / `Korea`

## 文章字數特性

- 技術筆記：50-150 行，精簡實用，不廢話
- 旅遊遊記：200-1300 行，照片砸滿，細節多
- 生活/日記：40-60 行，故事驅動

# 通用寫作指南 — 消除 AI 味

與各專案規則（CLAUDE.md）搭配使用。寫作前中後對照檢查。

## 禁止清單

| 模式                   | 替代                   |
| ---------------------- | ---------------------- |
| 粗體濫用               | 平實書寫，真需強調再用 |
| 破折號分隔             | 用「…」、逗號、拆句    |
| 標題大量冒號           | 改引號、逗號、省略副標 |
| 整篇敬體               | 斷定句為主，敬體限呼籲 |
| 全名詞止句             | 混動詞收尾、真實感受   |
| 驚嘆號過多             | 真強調才用             |
| 連接詞每段出           | 自然銜接，刪多餘       |
| 〜することができます   | 直接寫「〜できます」   |
| 濫用「活用」           | 寫「使用」「用」       |
| 〜についてご紹介します | 直接切入主題           |
| 具體行為→抽象動詞      | 直說                   |

- **不自動加議程目錄**、**不寫總結段落**、**不平均列舉**、**不「以下所示」→條列**、**不先結論再條列**

## 強化人味

- 實際碰過再寫，誠實寫失敗
- 術語首次附中文說明（Function Calling（函式呼叫））
- 大膽比喻（LLM 像哆啦 A 夢、容器像一次性虛擬電腦）
- 加入安心語句（其他地方預設即可）
- 預先處理常見卡點，不預設讀者背景

## 資訊密度

- 條列 ≤4 項，層級 ≤2 層，每項 ≤2 句
- 1 區塊 1 主題（投影片 1 訊息、部落格 1 段 1 主題）

## 圖表

- 重視外觀用 SVG，Mermaid 限簡單流程
- SVG 確認無截斷重疊

## 表記

- 行內程式碼前後半形空格，區塊標語言
- 主詞明確（NG：「會被設定」→ OK：「使用者設定」「系統自動設定」）
- 主動語態優先
