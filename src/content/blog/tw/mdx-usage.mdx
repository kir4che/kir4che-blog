## Lightbox（燈箱）

Lightbox 組件會透過 Image/Images 元件自動觸發。點擊下面的圖片可以開啟燈箱全屏檢視：

<Image
  src="https://cdn.kir4che.com/deploy-express-typescript-to-vercel/server-folder-structure.webp"
  alt="可點擊開啟燈箱的圖片"
  title="server-folder-structure"
  width="300px"
  className="cursor-pointer"
/>

或手動使用 `openLightbox` 函數：

```tsx
import { openLightbox } from '@/components/mdx/Lightbox';

const handleOpenLightbox = () => {
  openLightbox({
    slides: [
      { src: 'https://example.com/image1.jpg', alt: '圖片 1' },
      { src: 'https://example.com/image2.jpg', alt: '圖片 2' },
    ],
    index: 0,
  });
};
```
